# 🐞 BugRhoot

משחק טריוויה חי רב-משתתפים בסגנון Kahoot — עם טוויסט: **השאלות נוצרות on-the-fly ע"י Claude** מתוך חומרים שהאדמין מעלה (טקסט, PDF, קוד, markdown).

## איך זה עובד

1. **מסך אדמין** — יוצרים "קונטיינר משחק" (חידון):
   - תיאור מיקוד לשאלות (אופציונלי — ריק = ה-AI בוחר עומק ומיקוד בעצמו)
   - העלאת חומרי בסיס — השאלות מתבססות **אך ורק** עליהם
   - מספר שאלות וזמן לשאלה
2. **אירוח משחק** — נוצר PIN בן 6 ספרות + QR; השחקנים מצטרפים מהדפדפן/טלפון עם כינוי, בזמן שה-AI יוצר את השאלות ברקע.
3. **משחק חי** — כל שאלה עם 4 אפשרויות (כולל שאלות ניתוח קוד); הניקוד משקלל נכונות ומהירות תגובה בנוסחת Kahoot + בונוס רצף; בסוף — פודיום 🥇🥈🥉.

## התקנה והרצה (localhost)

```bash
npm install
cp .env.example .env    # ולהזין ANTHROPIC_API_KEY
npm run dev             # שרת על :3000, ממשק על :5173
```

- ממשק: http://localhost:5173 (אדמין: `/admin`, הצטרפות: `/join`)
- טלפונים ברשת המקומית מצטרפים דרך ה-QR שמוצג בלובי המארח.

### הרצת פרודקשן (תהליך אחד)

```bash
npm run build
npm start               # מגיש את הכול על :3000
```

זו בדיוק הצורה שתיפרס בהמשך לשרת ייעודי (pm2 + nginx/certbot מול פורט 3000).

## פיתוח ובדיקות

- **מצב שאלות דמה** (בלי לקרוא ל-API): `MOCK_QUESTIONS=1 npm run dev -w server`
- **בדיקת e2e** (מדמה מארח + שני שחקנים במשחק מלא): כשהשרת רץ עם `MOCK_QUESTIONS=1` —

```bash
npm run test:e2e
```

## פריסה לאינטרנט

האפליקציה היא שרת Node מתמשך אחד (WebSockets + SQLite) — מתאימה ל-**Railway / Render / Fly.io** או VPS. היא **לא** מתאימה ל-Vercel/serverless בלי שכתוב.

בכל הפלטפורמות התהליך זהה — הן מזהות את ה-`Dockerfile` שבשורש:

1. דחפו את הריפו ל-GitHub וחברו אותו לפלטפורמה (או `railway up` / `fly deploy` מה-CLI).
2. הגדירו משתני סביבה:
   - `ANTHROPIC_API_KEY` — חובה
   - `ADMIN_PASSWORD` — **חובה באינטרנט!** מגן על מסך האדמין ועל פתיחת משחקים (אחרת כל גולש ישרוף לכם קרדיטים)
3. הוסיפו volume מתמשך הממופה ל-`/data` (שם נשמר מסד הנתונים והחומרים).
4. זהו — ה-QR והקישורים מתאימים את עצמם אוטומטית לכתובת הציבורית.

## מבנה

```
server/   Express + Socket.IO + better-sqlite3 + Claude API (יצירת שאלות)
client/   React (Vite) — אדמין, מארח, שחקן; עברית RTL
```

- מסד הנתונים והחומרים נשמרים ב-`server/data/` (נוצר אוטומטית).
- משחקים חיים מתנהלים בזיכרון; PIN מתפנה בסיום המשחק.
